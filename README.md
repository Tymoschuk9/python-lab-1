# Мета
Ознайомитися з принципами організації професійного Python-проєкту, налаштуванням середовища, структурою src-layout та системою контролю версій Git.

## Опис алгоритму (Варіант №3: Інтернет-магазин)
Проєкт реалізовано з використанням архітектури `src-layout`.
- **models.py**: Містить клас `Product` (dataclass) з обчислюваною властивістю `total_value`.
- **services.py**: Містить бізнес-логіку: фільтрацію за категорією, пошук товару за назвою, визначення найдорожчого товару та підрахунок загальної вартості залишків на складі.
- **main.py**: Точка входу, що ініціалізує список товарів, демонструє роботу сервісів та виводить результат у консоль.

Проєкт відповідає вимогам:
- Використано `type hints`.
- Використано структуру модулів.
- Налаштовано `pyproject.toml` для встановлення пакета.
- Реалізовано 3 логічні коміти: 
  1. `Create project structure` (ініціалізація та конфіги)
  2. `Add product model and business logic` (models.py, services.py)
  3. `Add application entry point and documentation` (main.py, README.md)

## Висновок
Під час виконання лабораторної роботи було опановано навички організації Python-проєктів професійного рівня. Використання структури `src-layout` та файлу `pyproject.toml` дозволяє чітко розмежувати програмний код від конфігураційних файлів, що значно полегшує подальшу підтримку та масштабування застосунку. Використання `Git` забезпечує контроль версій, що є критично важливим для розробки.
