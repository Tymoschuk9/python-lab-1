# Мета
Ознайомитися з принципами професійної організації Python-проєктів, включаючи використання src-layout, керування залежностями через pyproject.toml, роботу з Git та структурування коду на модулі.

## Опис алгоритму (Варіант №3: Система банківських рахунків)
1. **Структура проєкту**: Використано стандартний `src-layout`, де код знаходиться у папці `src/bank_system/`.
2. **Моделі даних**: Створено `models.py` з `dataclass` `BankAccount`, що містить ім'я клієнта, номер рахунку та поточний баланс.
3. **Бізнес-логіка**: У модулі `services.py` реалізовано функції для маніпуляцій з даними: `deposit` (поповнення), `withdraw` (списання з перевіркою на від'ємний баланс), `find_account` (пошук за номером) та `calculate_total_balance`.
4. **Точка входу**: Файл `main.py` забезпечує демонстрацію функціоналу та містить конструкцію `if __name__ == "__main__":`.
5. **Контроль версій**: Проєкт ініціалізовано через `git init`, налаштовано `.gitignore` для виключення системних файлів та середовища `.venv`. Процес розробки розділено на логічні коміти: ініціалізація, бізнес-логіка та фіналізація з документацією.

## Висновок
У ході лабораторної роботи було успішно створено структурований Python-проєкт. Опановано навички створення віртуального середовища, модульного програмування та керування версіями. Проєкт готовий до подальшого розширення, наприклад, додавання постійного сховища даних або складнішої валідації вводу користувача.
