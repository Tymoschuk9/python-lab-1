# Мета
Освоїти принципи створення професійного Python-проєкту, використовуючи `src-layout`, ізольовані віртуальні середовища, систему керування версіями Git та модульну архітектуру.

## Опис алгоритму
Проєкт «Система банківських рахунків» реалізовано за допомогою наступних компонентів:
1. **Data Model**: Клас `BankAccount` (у файлі `models.py`), що зберігає стан рахунку та містить методи для виконання транзакцій.
2. **Business Logic**: Модуль `services.py`, що містить функції для пошуку рахунків та агрегації фінансових даних.
3. **Entry Point**: `main.py` забезпечує ініціалізацію об'єктів та демонстрацію функціоналу.
4. **Конфігурація**: Файл `pyproject.toml` забезпечує коректне встановлення проєкту в режимі `editable`, а `.gitignore` виключає технічні файли та віртуальне оточення з системи контролю версій.

## Висновок
У ході лабораторної роботи було успішно переведено навчальний скрипт у структуру повноцінного проєкту. Використання `src-layout` забезпечує чітке розділення коду та тестів, що відповідає сучасним стандартам розробки. Впровадження `Git` дозволило отримати навички трекінгу змін та організації розробки через систему комітів. Створення ізольованого середовища `venv` та використання `pyproject.toml` гарантують відтворюваність проєкту в інших середовищах.
